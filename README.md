# 📔 دفتر — مساحتك الشخصية للحياة والأفكار

تطبيق شخصي عربي (RTL) يجمع المهام والأهداف والعادات واليوميات والقوائم
والملاحظات والمصروفات والمراجعة في مساحة واحدة هادئة.

موقع ثابت (Static) لا يحتاج خادماً خلفياً، وكل البيانات تُحفظ على جهازك
داخل `localStorage`. يعمل على الجوال والحاسوب، بوضعين نهاري وليلي، ويدعم
تثبيته كتطبيق PWA.

## 🚀 التشغيل

### مباشرة
افتح `index.html` بأي متصفح حديث. بعض ميزات PWA (مثل التثبيت والعمل دون
اتصال) تحتاج تشغيله من خادم أو نشره على HTTPS.

### محلياً عبر الشبكة
```bash
cd daftar
python3 serve.py 8899
# افتح: http://<عنوان-الجهاز>:8899
```

### حارس دائم في الخلفية
```bash
python3 watchd.py
python3 watchd.py status
python3 watchd.py stop
```

## 🌐 النشر

### GitHub Pages
ارفع المجلد إلى مستودع GitHub ثم فعّل Pages. ملف
`.github/workflows/pages.yml` ينشر الموقع تلقائياً عند الدفع إلى `main`.

### نفق سريع
```bash
cloudflared tunnel --url http://localhost:8899
```

## 🔒 الخصوصية والبيانات

- لا يوجد تسجيل دخول؛ يفتح التطبيق مساحة شخصية واحدة مباشرة.
- البيانات محفوظة محلياً في `localStorage` على هذا الجهاز فقط.
- قفل اليوميات اختياري ويُخزّن رمزه كبصمة مشفّرة (Salted SHA-256).
- يمكن تصدير نسخة JSON واستيرادها من الإعدادات.
- المزامنة الاختيارية عبر WebDAV تحتاج رابط خدمة متوافقاً وتُرسل البيانات
  إليه فقط عند تفعيلها.
- لا توجد حسابات سحابية أو تتبّع أو إعلانات.
